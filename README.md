# MetricDash
```bash
cd d:\it\md\.net_csharp_gerdzhikova\MetricDash
dotnet run --project MetricDash.Cli -- --file metrics.csv
```
Анализатор метрик из CSV-файлов с интерактивной визуализацией и расширенной аналитикой. Проект демонстрирует чистую архитектуру, разделение логики и UI, а также гибкую систему настроек.

## Возможности

### Ядро
- **Универсальный парсер CSV**: автоопределение колонок, регистронезависимый поиск, поддержка временных меток
- **Статистический движок**: расчёт `min/max/avg`, трендов, экспорт в JSON/CSV
- **Типобезопасные модели**: `MetricSeries`, `MetricPoint`, `CsvMetadata`
- **Событийная архитектура**: готово для расширения и тестирования

### Консольный интерфейс (CLI)
```bash
# Показать доступные метрики в файле
dotnet run --project MetricDash.Cli -- --file metrics.csv

# Анализ выбранных метрик
dotnet run --project MetricDash.Cli -- --file metrics.csv --metrics cpu_percent,memory_mb

# Экспорт статистики
dotnet run --project MetricDash.Cli -- --file metrics.csv --metrics response_time_ms --export json
```
Атрибуты
```bash
--file <path> Путь к CSV-файлу (обязательно)
--metrics col1,col2 Колонки для анализа (через запятую)
--export json, csv Формат вывода статистики
--help Показать справку
```
### Графический интерфейс (WinForms)
Горячие клавиши
```bash
F1 Справка по управлению
F5 Обновить текущую вкладку
Ctrl + E Экспорт данных в JSON/CSV
Ctrl + S Сменить тему
Ctrl + 1 Переключиться на вкладку "График"
Ctrl + 2 Переключиться на вкладку "Аналитика"
```
#### Вкладка "График"
    Кастомная отрисовка Line / Bar / Area
    Динамические чекбоксы метрик из загруженного файла
    Легенда с цветовой кодировкой
    Сетка и оси с подписями значений

#### Вкладка "Аналитика"
    Карточки статистики: avg, min/max, тренд с цветовой индикацией (▲/▼)
    Таблица данных с последними 100 точками
    Автоматическое обновление при изменении выбора метрик
#### Настройки
    Мгновенное переключение темы Light / Dark
    Автосохранение предпочтений в winforms_settings.json
